# Sistema de Registro de Calificaciones

## Descripción

Programa desarrollado para registrar las calificaciones de estudiantes,
calcular su promedio y determinar si aprobaron o reprobaron.

## Funcionalidades

- Registrar nombre del estudiante.
- Registrar tres calificaciones.
- Calcular el promedio.
- Determinar si el estudiante aprobó o reprobó.
- Registrar varios estudiantes.
- Validar las entradas del usuario.
- Controlar errores de entrada.

## Validaciones

Las calificaciones deben estar entre 0 y 100.

El nombre del estudiante no puede estar vacío.

El programa controla entradas que no sean numéricas.

## Manejo de errores

El programa detecta datos incorrectos, informa al usuario y solicita
nuevamente la información.

## Pruebas realizadas

- Datos válidos.
- Calificación negativa.
- Calificación superior a 100.
- Nombre vacío.
- Texto en una calificación.
